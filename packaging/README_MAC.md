# Train Monitoring for macOS

## Open the application

1. Extract the complete ZIP.
2. Keep `Train Monitoring.app` and the accompanying files together.
3. Control-click `Train Monitoring.app`, choose **Open**, and confirm **Open** on the first launch.
4. Select the `raw_data` folder containing the timestamped FBG recordings.

The application opens the dashboard in the default browser. The raw dataset is not included in the ZIP and Python is not required.

To select another dataset, Control-click `Choose_Train_Monitoring_Mac_Data_Folder.command`, choose **Open**, and select the new `raw_data` folder.

## macOS security

The application is not signed with an Apple Developer certificate. If macOS blocks it, open **System Settings → Privacy & Security** and choose **Open Anyway** for Train Monitoring. Only do this for a package received from a trusted source.

Use the Apple Silicon package on M1, M2, M3, M4, or newer Macs. Use the Intel package on Intel-based Macs.
