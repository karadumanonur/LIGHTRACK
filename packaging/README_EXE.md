# Train Monitoring for Windows

Keep `TrainMonitoring.exe` and the `_internal` folder together. The application will not work if only the executable is copied.

## Use

1. Double-click `TrainMonitoring.exe`.
2. On first launch, select the `raw_data` folder containing the measurement periods.
3. Keep the console window open while using the dashboard.
4. Close the console window or press `Ctrl+C` to stop Train Monitoring.

To select a different dataset later, double-click `Choose_Train_Monitoring_Data_Folder.cmd`.

Python does not need to be installed on the destination computer. The raw FBG recordings are not included and must be copied or connected separately.
