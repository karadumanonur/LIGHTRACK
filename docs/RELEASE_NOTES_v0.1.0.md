# LIGHTRACK FBG Analysis v0.1.0

Initial research release of Asude's LIGHTRACK FBG analysis application.

## Included

- Interactive inspection by date, recording, detection head and physical FBG sensor.
- Raw wavelength, axle-count and derivative views.
- FFT, Welch PSD, wavelet, EMD and optional VMD frequency analysis.
- Record-specific self-calibrating axle detection.
- Windows and macOS application packages that do not require a separate Python installation.

## Data

Raw FBG recordings are not included. Select the local `raw_data` folder when the application starts. This keeps the large measurement dataset outside GitHub while allowing the same application to analyse both measurement periods.

## Research status

This is a research prototype. Axle counts and sensor-health indicators must be validated before operational use.
